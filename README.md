# Карточка персонажа НРИ

Веб-приложение (PWA) для карточки персонажа самодельной настольной ролевой системы: генетический/магический/технический пути, point-buy характеристики, предметы и умения с бонусами, боевая памятка, прогрессия уровней, мастер-вид с импортом персонажей игроков и треем лута.

Работает полностью локально в браузере (данные хранятся в IndexedDB на устройстве), сервер не требуется.

## Запуск для разработки

```bash
npm install
npm run dev
```

Откроется на `http://localhost:5173`.

## Сборка

```bash
npm run build
```

Результат — статические файлы в папке `dist/`. Их можно:

- открыть локально (`npm run preview` после сборки);
- один раз залить на бесплатный статический хостинг — например [GitHub Pages](https://pages.github.com/), [Netlify](https://www.netlify.com/) (drag-and-drop папки `dist/`) или [Cloudflare Pages](https://pages.cloudflare.com/). Дальше сайт работает сам по себе, без вашего участия и без сервера.

На телефоне (Android/iPhone) открыть ссылку в браузере и через меню браузера выбрать «Добавить на экран» — приложение появится как иконка и будет работать офлайн.

## Данные

- Персонажи, боевая памятка и таблица прогрессии хранятся в IndexedDB браузера — при очистке данных сайта в браузере они удаляются.
- Кнопка «Экспорт в JSON» на карточке персонажа сохраняет файл, который можно переслать другому игроку или мастеру — он импортируется через кнопку «Импортировать JSON».
