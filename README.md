# Карточка персонажа НРИ

Веб-приложение (PWA) для карточки персонажа самодельной настольной ролевой системы: генетический/магический/технический пути, point-buy характеристики, предметы и умения с бонусами, боевая памятка, фиксированная таблица опыта по уровням, мастер-вид с импортом персонажей игроков и треем лута.

Работает полностью локально в браузере (данные хранятся в IndexedDB на устройстве), сервер не требуется.

## Запуск для разработки

```bash
npm install
npm run dev
```

Откроется на `http://localhost:5173`.

## Сборка

```bash
npm run build
```

Результат — статические файлы в папке `dist/`. Их можно:

- открыть локально (`npm run preview` после сборки);
- один раз залить на бесплатный статический хостинг — например [GitHub Pages](https://pages.github.com/), [Netlify](https://www.netlify.com/) (drag-and-drop папки `dist/`) или [Cloudflare Pages](https://pages.cloudflare.com/). Дальше сайт работает сам по себе, без вашего участия и без сервера.

На телефоне (Android/iPhone) открыть ссылку в браузере и через меню браузера выбрать «Добавить на экран» — приложение появится как иконка и будет работать офлайн.

## Данные

- Персонажи, трей предметов и история версий хранятся в IndexedDB браузера. При старте приложение просит у браузера постоянное хранилище, а на iPhone подсказывает добавить его на экран «Домой» (в обычной вкладке Safari стирает данные редко используемых сайтов).
- Сохранение идёт с задержкой в доли секунды и дополнительно при сворачивании страницы; раз в ~15 минут правок делается снимок прежней версии (кнопка «Ещё → История версий» на карточке). Удалённых персонажей можно вернуть из корзины внизу списка (30 дней).
- «Экспорт в JSON» и «Сохранить резервную копию» на телефоне открывают системное меню «Поделиться» с настоящим файлом (в Telegram/Instagram-браузерах скачивание файлов не работает); если меню недоступно — показывается текст для копирования, а импорт умеет принимать вставленный текст.
- «Сохранить картинкой» рисует три листа поверх бумажных шаблонов (основной — по выбранному пути, доп. информация, экипировка) (`src/assets/templates`, координаты полей — в `src/utils/sheetImage.ts`).
- Формат карточки версионируется (`schemaVersion`, `src/data/migrations.ts`): при любом несовместимом изменении данных увеличьте `CURRENT_SCHEMA_VERSION` и добавьте миграцию.

## Распознавание карточек (OCR)

Tesseract работает прямо в браузере. Воркер, ядро WASM и языковые данные (≈10 МБ) копируются из `node_modules` в `public/ocr` скриптом `scripts/copy-ocr-assets.mjs` (запускается перед `dev` и `build`, в git не хранится), отдаются с самого сайта и кэшируются сервис-воркером при первом использовании — дальше OCR работает без интернета.

## Проверки и деплой

```bash
npm run lint   # oxlint
npm test       # vitest: формулы, разбор эталонных карточек, миграции, учёт способностей
```

При каждом push в `main` GitHub Actions запускает lint, тесты и сборку и только потом публикует сайт на GitHub Pages — упавший тест блокирует деплой. Если правите разбор карточек (`src/utils/ocrParse.ts`), добавляйте текст новой карточки в `src/utils/ocrParse.test.ts`.
